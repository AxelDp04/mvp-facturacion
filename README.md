# MVP - Sistema de Facturación e Inventario

Este repositorio contiene un **Producto Mínimo Viable (MVP)** de un **Sistema de Facturación e Inventario** desplegado en GitHub Pages.

## 🚀 Demostración en Vivo
Accede al sistema funcional aquí:  
👉 **[Ver MVP en GitHub Pages](https://axeldp04.github.io/mvp-facturacion/)**

---

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura de la aplicación web.
* **Tailwind CSS (CDN):** Estilizado responsivo y moderno.
* **JavaScript (Vanilla JS):** Lógica del sistema y manipulación de eventos.
* **LocalStorage API:** Persistencia local de datos del inventario.

---

## ✨ Características del MVP
1. **Módulo de Inventario:**
   * Registro de productos (nombre, precio unitario, stock inicial).
   * Almacenamiento persistente en el navegador.
   * Vista de tabla con el listado de productos creados.

2. **Módulo de Facturación:**
   * Selección de productos del inventario y cantidad a facturar.
   * Cálculo automático del Subtotal.
   * Aplicación del **ITBIS (18%)** y cálculo del Total a Pagar.

3. **Módulo de Impresión:**
   * Función para imprimir o guardar en PDF la factura generada.
